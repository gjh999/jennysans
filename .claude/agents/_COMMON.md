# JennySans 팀원 공통 규칙 (모든 font-* 역할 파일이 이 문서를 전제한다)

1. **먼저 읽는다**: `<repo>\AGENTS.md`(단일 원본 룰) → 이 문서 → 자기 역할 파일 → `docs/ROADMAP.md` → `docs/PROGRESS.md`
   → 역할에 따라 `docs/research/*.md`, `docs/spec/*.md`, `.claude/skills/font-pipeline/SKILL.md`.
2. **한국어로 보고**한다. 코드·명령·경로·식별자·폰트 이름은 원문.
3. **추측 금지.** 라이선스·RFN·커버리지·메트릭은 **파일을 내려받아 fontTools 로 실측**하거나 원문 LICENSE 를 읽어 근거(URL·경로·명령·출력)를 적는다.
   못 확인했으면 "확인 못 함"이라고 쓴다. 검증 못 했으면 "검증했다"고 쓰지 않는다.
4. **산출물은 파일로 남긴다.** 최종 보고는 파일 절대경로 + 핵심 요약(15줄 이내) + **다음 사람이 필요한 것**.
5. **라이선스 무결**(AGENTS §5): OFL 1.1 원본만. 원본 RFN 을 이름에 쓰지 않는다. 원본 저작권 고지는 누적 유지. "무료지만 수정 금지" 폰트 제외.
   새 원본을 쓰면 AGENTS §5-1 대장에 한 줄 추가(출처 URL·버전·라이선스·RFN·SHA-256).
6. **실행환경**(AGENTS §2): Python 은 `PYTHONUTF8=1 python …`. FontForge 없음 → fontTools 만. 원본은 `sources/<이름>/` 에, 중간물은 `build/`, 릴리스는 `dist/`.
   임시 파일은 스크래치패드에. 큰 다운로드는 재사용(이미 있으면 SHA 만 확인).
7. **검증은 실제 실행으로**: fontTools 로 cmap/name/OS/2 를 읽어 확인, HarfBuzz 로 셰이핑, PIL/브라우저로 렌더 이미지. "파일이 생성됐다"는 검증이 아니다.
8. 비밀값은 출력·커밋하지 않는다(이 프로젝트엔 원칙적으로 없음).
9. 팀장 결정(AGENTS §7·§8, `docs/spec/`)을 임의로 바꾸지 않는다. 바꿔야 한다고 판단하면 **근거를 적어 보고**만 한다.
10. **소유 구역**(AGENTS §3-1)을 지킨다. 남의 구역 파일이 문제면 고치지 말고 보고(QA 는 `docs/qa/ISSUES.md` 티켓으로).
11. 작업이 끝나면 `docs/PROGRESS.md` 의 **자기 항목**을 갱신한다(무엇을·어디에·검증 결과·남은 것).
12. ⚠ Git Bash 긴 heredoc 은 깨진다 — 파일 생성은 Write 툴 또는 python 스크립트로. Python 스크립트는 파일로 저장해 실행한다.
13. 큰 작업은 중간 산출물을 먼저 파일로 저장하고 진행한다(세션이 끊겨도 남게).
14. 웹 조사 시 **1차 출처**(공식 GitHub 저장소·LICENSE 원문·릴리스 페이지)를 우선하고 블로그 요약은 보조로만.
