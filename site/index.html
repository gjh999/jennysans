제니산스JennySans

제니소프트의 웹·앱·게임·문서에서 공통으로 쓰는 범용 한글·영문(라틴) 고딕입니다. 현대 한글 11,172자 전부, 스페인어를 포함한 서유럽·중앙유럽 라틴, 그리스·키릴 기본, 한국 문서용 기호를 한 패밀리 9 웨이트와 변수 폰트 하나에 담았습니다. 개성보다 중립성과 판독성을 우선한 본문용 서체입니다.

한국어 본문

글꼴은 말을 담는 그릇입니다. 화면이 작든 크든, 종이든 유리든, 읽는 사람이 글꼴을 의식하지 않고 내용에만 머물 수 있어야 합니다.

제니산스는 그래서 개성보다 중립을, 장식보다 판독을 택했습니다. 본문에 오래 머무는 글자일수록 튀지 않아야 하고, 굵기를 바꿔도 줄의 높이가 흔들리지 않아야 합니다. 아홉 가지 굵기가 같은 수직 메트릭을 공유하는 이유입니다. 제목에서 900을, 캡션에서 300을 써도 같은 문단 안에서 줄 간격이 어긋나지 않습니다.

한글 11,172자를 모두 담았기 때문에 「똠방각하」·「뷁」·「쒔」 같은 드문 음절도 빠지지 않고, 문서에 자주 나오는 ※ ① ㉠ ㈜ ㎏ ㎡ ℃ 같은 기호와 괘선(─ ┌ ┼ ┘)까지 같은 굵기·같은 회색도로 그려집니다. 표와 코드, 각주와 단위가 섞인 실무 문서에서 서체가 흐트러지지 않는 것이 이 글꼴의 목표입니다.

English

Type is a vessel for words. A text face should disappear into the reading — the same shapes at 12 pixels on a phone and at 12 points on paper, with numbers that line up in tables and punctuation that never shouts. JennySans keeps nine weights on one vertical rhythm, so a heading at 900 and a caption at 300 sit on the same baseline grid.

Español

La tipografía es un recipiente para las palabras. ¿Qué pide un texto largo? Que la letra no se note: la misma forma a 12 píxeles en el móvil y a 12 puntos en papel, con cifras que se alinean en las tablas. JennySans mantiene nueve pesos sobre un mismo ritmo vertical, señor.

How to use

사용법

플랫폼을 고르세요. 코드 블록은 오른쪽 위 버튼으로 복사할 수 있습니다. 자세한 내용은 zip 안의 README-설치안내.txt 와 저장소의 docs/INSTALL.md.

  1. 데스크톱 zip을 받아 풀고, TTF 9개를 모두 선택 → 마우스 오른쪽 → 설치(내 계정) 또는 모든 사용자용으로 설치(관리자 권한, 서버·공용 PC).
  2. 이미 JennySans 가 설치돼 있으면 폰트를 쓰는 프로그램을 모두 닫고 설정 → 개인 설정 → 글꼴에서 JennySans 항목(웨이트별로 여러 개)을 먼저 제거한 뒤 설치합니다.
  3. 옛 모양이 계속 보이면 재부팅하거나 관리자 PowerShell 에서 폰트 캐시를 재시작합니다.
Stop-Service FontCache; Start-Service FontCache

설치 확인 — 아래 명령에 JennySans, JennySans Light … 가 보이면 정상입니다(GDI 기준 8개 패밀리명 — Regular·Bold 는 JennySans 하나로 묶임).

Add-Type -AssemblyName System.Drawing
[System.Drawing.Text.InstalledFontCollection]::new().Families | Where-Object Name -like 'JennySans*' | Select-Object -ExpandProperty Name
  1. TTF 를 더블클릭 → 서체 설치(Font Book / 서체 관리자). 여러 파일을 선택해 Font Book 창에 끌어다 놓아도 됩니다.
  2. 설치 위치: 사용자(~/Library/Fonts, 내 계정) 또는 컴퓨터(/Library/Fonts, 모든 계정 — 관리자 암호). Font Book 설정에서 기본 위치를 바꿀 수 있습니다.
  3. 교체할 때는 Font Book 에서 기존 JennySans 패밀리를 제거 → 새 파일 설치 → 앱 재시작. macOS 는 패밀리 "JennySans" 하나에 9 스타일로 보입니다.
cp JennySans-*.ttf ~/Library/Fonts/        # 터미널로 설치할 때(내 계정)
  • 한글(HWP): 글꼴 목록에 「제니산스」(JennySans)와 웨이트별 항목(「제니산스 Light」, 「제니산스 Medium」 …)이 따로 보입니다. 굵기는 목록에서 고르세요. 「제니산스」(Regular)에서 진하게(Ctrl+B)를 누르면 진짜 Bold 파일로 바뀌지만, Light 등 다른 항목에서 진하게를 누르면 합성 굵게가 되어 품질이 떨어집니다.
  • MS Office(Word·Excel·PowerPoint): 글꼴 상자에 JennySans, JennySans Light, JennySans SemiBold … 로 웨이트별 항목이 나옵니다. 문서를 다른 PC 로 보낼 때는 Word 옵션 → 저장 → 파일에 글꼴 포함을 켜도 됩니다(OFL 은 임베딩을 허용하며 폰트의 fsType 이 0 입니다).
  • 한글·Office 는 변수 폰트의 축 조절을 지원하지 않습니다 — 문서용은 정적 TTF 9종을 설치하세요.
  • 웨이트가 따로 보이는 이유: Windows 의 옛 폰트 API(GDI)는 한 패밀리에 Regular/Bold/Italic/Bold Italic 4개만 둘 수 있어, 나머지 웨이트는 OpenType 관례대로 "JennySans Light" 같은 별도 이름(name ID 1)을 갖습니다. Pretendard·Noto Sans KR 등도 같습니다.
  • Photoshop · Illustrator · InDesign · Figma · 브라우저는 name ID 16/17 을 읽어 패밀리 "JennySans" 하나에 스타일 9개(Thin … Black)로 보입니다.
  • 변수 폰트(JennySansVariable.ttf)를 설치하면 "JennySans Variable" 패밀리가 따로 생기고 굵기 슬라이더가 붙습니다. 정적과 변수를 동시에 설치해도 이름이 달라 충돌하지 않습니다.
  • 이탤릭이 없는 서체입니다 — 가짜 기울임(Faux Italic)은 쓰지 마세요.
  • Photoshop 문자 패널의 OpenType 메뉴에서 분수(frac)·서수(ordn)·위첨자(sups)·스타일 세트(ss01 …)를 켤 수 있습니다.

① 분할 CSS — 한국어 페이지 기본 권장

페이지에 실제로 쓰인 글자가 든 조각(unicode-range, 웨이트당 99 조각)만 내려받습니다. 첫 화면 ≈ 라틴 조각 1개 + 한글 조각 2~3개.

<link rel="preload" as="font" type="font/woff2" crossorigin
      href="https://font.jennysoft.co.kr/v/1.001/web/subset/JennySans-Regular.subset.123.woff2">
<link rel="stylesheet" href="https://font.jennysoft.co.kr/v/1.001/css/jennysans-dynamic-subset.css">
<style>
  html {
    font-family: "JennySans", "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif;
    font-synthesis: none;                    /* 가짜 기울임·가짜 굵게 금지 */
  }
  table { font-variant-numeric: tabular-nums; }   /* 표 숫자 자릿수 맞춤 */
</style>

② 전체본 CSS — 인트라넷·오프라인·웨이트 1~2개

<link rel="stylesheet" href="https://font.jennysoft.co.kr/v/1.001/css/jennysans.css">

③ 변수 폰트 CSS — 한 페이지에 웨이트 4개 이상

<link rel="stylesheet" href="https://font.jennysoft.co.kr/v/1.001/css/jennysans-variable.css">
<style> h1 { font-family: "JennySans", sans-serif; font-weight: 650; } </style>

네 CSS 모두 font-family: "JennySans" 로 같은 이름을 선언하므로 하나만 링크하세요(둘 이상이면 이중 다운로드). /v/1.001/ 경로는 내용이 바뀌지 않는 영구 캐시(immutable)이고, /latest/ 는 최신 버전 별칭(5분 캐시)입니다. 운영 서비스는 고정 버전 경로를 쓰세요.

④ 직접 서빙(self-host) — CORS 필수

웹 zip의 css/ 와 web/ 을 같은 상대 구조로 올리면 CSS 를 고칠 필요가 없습니다. 페이지와 폰트의 도메인이 다르면 폰트 서버가 Access-Control-Allow-Origin 을 내야 합니다 — 없으면 curl 은 200 이어도 브라우저는 조용히 폴백 폰트로 그립니다.

# nginx 예시
location ~* \.(woff2|ttf)$ {
    types { font/woff2 woff2; font/ttf ttf; }
    add_header Access-Control-Allow-Origin "*" always;
    add_header Cache-Control "public, max-age=31536000, immutable" always;
    gzip off;   # WOFF2 는 이미 Brotli 압축
}

jsDelivr(npm) 경로 https://cdn.jsdelivr.net/npm/jennysans@1.0.1/dist/css/jennysans-dynamic-subset.css 는 npm 공개 후 동작합니다.

정적 TTF 를 assets/fonts/ 에 복사하고 pubspec.yaml 에 웨이트별로 선언합니다(Flutter 는 데스크톱에서 WOFF2 를 지원하지 않으므로 TTF). 실제로 쓰는 웨이트만 선언하면 앱이 작아집니다(TTF 1개 ≈ 2.6 MB).

flutter:
  fonts:
    - family: JennySans
      fonts:
        - asset: assets/fonts/JennySans-Light.ttf
          weight: 300
        - asset: assets/fonts/JennySans-Regular.ttf
          weight: 400
        - asset: assets/fonts/JennySans-Medium.ttf
          weight: 500
        - asset: assets/fonts/JennySans-SemiBold.ttf
          weight: 600
        - asset: assets/fonts/JennySans-Bold.ttf
          weight: 700
MaterialApp(theme: ThemeData(fontFamily: 'JennySans', useMaterial3: true));
Text('제니산스 ¿Qué tal, señor?', style: TextStyle(fontWeight: FontWeight.w600));

// 변수 폰트 하나로 대체할 때
Text('제니산스', style: TextStyle(fontFamily: 'JennySansVariable', fontVariations: [FontVariation('wght', 650)]));

Flutter 웹(CanvasKit)은 선언된 폰트 파일을 앱 시작 시 전부 내려받으므로 웨이트 수를 줄이는 것이 가장 큰 절감입니다. 사내 앱 안에서만 쓰는 서브셋본은 이름을 바꿀 필요가 없습니다(외부 재배포 시에만 OFL 조항 3).

Unity — TextMesh Pro

  1. JennySans-<Weight>.ttf 를 Assets/Fonts/ 에 넣고 Window → TextMeshPro → Font Asset Creator.
  2. 한글 11,172자를 정적 아틀라스에 다 굽지 마세요(4096² 에서 글립당 약 38 px 로 품질 부족). Atlas Population Mode = Dynamic(+ Multi Atlas Textures) 또는 KS X 1001 2,350자 정적 + Dynamic 을 권장합니다.
  3. Font Asset 의 Font Weights 표에 Bold 등 다른 웨이트 에셋을 연결하면 <b> 가 합성 굵게가 아니라 진짜 Bold 파일을 씁니다. 범위 밖 문자(한자 등)는 Fallback Font Assets 로.

Godot 4

TTF 를 프로젝트에 넣으면 FontFile 로 임포트됩니다. Theme 의 default font 로 지정하고, 변수 TTF 는 FontVariation 으로 굵기를 고릅니다. Import 도크에서 Hinting Light, Antialiasing LCD/Gray, 크기가 계속 변하는 텍스트는 MSDF.

var fv := FontVariation.new()
fv.base_font = load("res://fonts/JennySansVariable.ttf")
fv.variation_opentype = { "wght": 700 }
$Label.add_theme_font_override("font", fv)

What we changed

원본과 무엇이 다른가

JennySans 는 새로 그린 서체가 아니라, 한국 문서·다국어 실무에 맞게 재구성하고 검증한 OFL 배포판입니다. 아래 수치는 원본 Pretendard 1.3.9 Regular 와 JennySans 1.001 Regular 의 cmap 을 직접 비교한 실측값입니다(tools/origin_diff.py).

두 원본 어디에도 없어 직접 만든 4자

⅔ ∼ ≒ ◈

KS X 1001 에 있는 글자인데 Pretendard·Noto Sans KR 둘 다 갖고 있지 않았습니다. ⅔ 는 ⅓ 의 구조를 그대로 재현해 조립했고, ∼ 는 ∽ 을 좌우 반전, ≒ 는 = 와 · 두 개, ◈ 는 ◇ 와 ◆ 를 합쳐 만들었습니다. 새로 그린 것이 아니라 원본 부품을 조합한 것이라 굵기·획 두께가 주변 기호와 어긋나지 않습니다.

글자 수 말고 달라진 것

  • 수직 메트릭 통일 — 9 웨이트와 변수 폰트가 같은 ascender/descender(1950/−494)를 씁니다. 굵기를 바꿔도 줄 높이가 변하지 않습니다.
  • 웹 분할 — WOFF2 를 웨이트당 99조각(전부 990개 파일)으로 나눠, 페이지에 실제로 쓰인 글자의 조각만 내려받습니다. 실측: 라틴 전용 30.4 KB · 한국어 한 문장 83.4 KB · 한 문단 102.9 KB(tools/first_paint.py).
  • 검사 도구 지적 결함 수정 — fontbakery 가 지적한 6건(대문자 짝 DŽ 누락, 중첩 컴포넌트, Mac name 레코드, prep 없음, 변환 컴포넌트 등)을 고쳤습니다(docs/qa/ISSUES.md).

저작권은 괜찮은가요

한국 법에서 글자체 도안 자체는 저작물이 아닙니다(대법원 1996. 8. 23. 선고 94누5632 — 서체 도안의 저작물성 부정). 반면 폰트 파일(프로그램)은 컴퓨터프로그램저작물로 보호됩니다(대법원 2001. 6. 29. 선고 99다23246 — 서체 파일의 프로그램 저작물성 인정). 그래서 중요한 것은 "모양이 닮았는가"가 아니라 파일을 쓸 권리가 있는가입니다.

JennySans (Korean name 제니산스) is a general-purpose sans-serif type family by JennySoft for Korean & English (Latin) text, released under the SIL Open Font License 1.1 (Reserved Font Names "JennySans" and "제니산스"). It covers all 11,172 modern Hangul syllables, compatibility and conjoining jamo, ASCII, the complete Latin-1 Supplement and Latin Extended-A (Spanish, Portuguese, French, German, Polish, Czech, Turkish, Baltic and Nordic languages, …), basic Greek and Cyrillic, and KS X 1001 Korean document symbols, in 9 static weights (Thin 100 – Black 900) with identical vertical metrics plus one variable font (wght 100–900); no italics. Derived from Pretendard 1.3.9 (itself built on Inter, Source Han Sans and M PLUS 1) and Noto Sans KR 2.004 — no glyphs were drawn from scratch. Free for commercial use, modification, redistribution and embedding; the font files may not be sold by themselves, and modified versions must not use the reserved names.
